# Session Briefings

When I ask a status-type question - "what are you doing?", "what's the status?", "what do you need from me?", "where were we?", "catch me up" - **assume I have zero memory of this session**, especially if the session was just resumed or compacted. I run many agents in parallel and cannot tell them apart.

Do not answer as if I've been following along. Invoke the catch-up workflow
(`/catch-up` in Claude Code, `$catch-up` in Codex) and answer in its format:
TL;DR, goal, done so far, in flight, open decisions with tradeoffs and a
recommendation, and what you need from me. Expand any codenames or shorthand
invented during the session - I never saw the naming happen.
